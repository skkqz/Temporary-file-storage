# Temporary file storage API

Это FastAPI-приложение для управления файлами с функциональностью временного хранения файлов. Пользователи могут загружать файлы с указанием срока их хранения, скачивать их по ссылке, просматривать информацию о файлах и удалять файлы вручную или автоматически.

## Функциональность

- **Загрузка файлов** с указанием времени жизни (в минутах).  
- **Ограничение размера файлов**: 
  - Максимальный размер одного файла: 5 МБ.  
  - Общий лимит файлов на сервере: 100 МБ.  
- **Хранение метаданных** в Redis:
  - Путь к файлу.
  - Время истечения срока хранения.
  - URL для скачивания.
- **Удаление файлов** вручную или автоматически:
  - Автоматическое удаление через Celery.
- **Скачивание файлов** по уникальной ссылке.  
- **Просмотр информации о файле**: время истечения, имя файла и URL.  

---

## Стек технологий

- **FastAPI** — веб-фреймворк для создания API.  
- **Redis** — хранилище ключ-значение для управления метаданными.  
- **Celery** — обработка задач для автоматического удаления файлов.  
- **Loguru** — расширенное логирование для отладки и мониторинга.  
- **Docker** (опционально) — для развертывания Redis и приложения.

## Установка и запуск

### Шаг 1. Клонируйте репозиторий

~~~ bash
git clone https://github.com/ваш-репозиторий/file-management-api.git
cd Temporary-file-storage
~~~

### Шаг 2. Установите зависимости
- **Создайте виртуальное окружение**
~~~ Python 
python -m venv venv
source venv/bin/activate  # Linux/MacOS
venv\Scripts\activate  # Windows
~~~
- **Установите зависимости**
~~~ Python 
pip install -r requirements.txt
~~~

### Шаг 3. Настройте переменные окружения
- **Создайте файл .env в корне проекта и укажите следующие настройки**
~~~ Python
REDIS_PORT=6379
REDIS_PASSWORD=password
REDIS_HOST=localhost
REDIS_USERNAME=user
~~~

### Шаг 4. Запустите Redis
- **Если Redis не установлен, вы можете запустить его через doker-compose:**
~~~ Python
docker-compose up -d
~~~

### Шаг 5. Запустите Celery
- **Выполните команду для запуска celery_app:**
~~~Python
celery -A celery_app.task_delete_file.celery_app worker --loglevel=INFO -P solo
~~~

### Шаг 6. Запустите приложение FastApi
- **Выполните команду**
~~~Python
python main.py
~~~

- **Ознакомится с документацией вы можете: [Документация](http://localhost:8000/docs#/)**
